# Ship and Stop
* Ship first, refine later: get a usable artifact out, then add detail.
* Once you judge "that's enough", your next output must be the artifact itself — not another check.
* Write code before inspecting the environment or library internals; the compiler is the faster answer.
* Every command must end on its own: non-interactive, under a timeout, never waiting on a live screen.
* One smoke check per feature; if it hangs or fails, report it instead of writing another script.
* "Just simple / that's enough / stop" closes the task: note new doubts, don't chase them.
