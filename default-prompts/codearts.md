# Check Once, Then Ship
* Ship first, refine later: get a usable artifact out, then add detail.
* Every check answers one question in one attempt; if it returns nothing, drop it and deliver.
* One build, one test, one smoke run: no clean rebuild, no lockfile juggling, no re-verification pass.
* Reuse the numbers you already have; a measurement that roughly matches the spec has passed.
* "Just simple / that's enough / stop" closes the task: note new doubts, don't chase them.
